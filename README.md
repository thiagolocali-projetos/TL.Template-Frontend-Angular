# TL.Template - Frontend Angular

Template padrão para projetos Angular no TLServer.

## Como usar

1. Crie um novo repositório a partir deste template
2. Ajuste as portas em `docker-compose.dev.yml` e `docker-compose.prod.yml`
3. Renomeie `NOME_PROJETO` nos docker-compose para o nome do seu projeto
4. Rode `CloneProjeto.bat` com a URL do seu repo

## Portas padrão

| Ambiente | Porta |
|----------|-------|
| DEV      | 4200  |
| PROD     | 4201  |

## Acesso após clone

- DEV:  `http://dev.seuprojeto.tlservidor`
- PROD: `http://prd.seuprojeto.tlservidor`
